# 🚌 Egare Bus Ticketing App

A cross-platform bus ticketing app built with **AngularJS** and the **Ionic Framework**, designed to deliver a smooth and intuitive experience on both mobile and desktop platforms.

---

## 💡 Overview

This project focuses on front-end development for Egare, a bus ticketing application. The app provides users with the ability to browse, book, and manage their bus travel through a responsive and user-friendly interface.

---

## ✨ Key Features

- ✅ Developed front-end features for both **mobile and desktop** versions.
- ✅ Built **user-friendly interfaces** using AngularJS and the Ionic framework.
- ✅ Ensured **cross-platform integration and functionality**.
- ✅ Applied **responsive design best practices** for various screen sizes.
- ✅ Collaborated closely with **cross-functional teams** to enhance user experience.

---

## 🛠️ Technologies Used

- **AngularJS**
- **Ionic Framework**
- **HTML5 / CSS3**
- **JavaScript**
- **Responsive Design**
